# DEVALBO-CORE PRINCIPLES

This document consolidates the default project principles, positions, and positions used by devalbo for software projects. Admittedly, they may not be ideal for all scenarios, but given no other constraints or requirements, these principles espouse testability and maintainability for a modern integrated software project.


## Philosophy

Ideally, projects should run and be deployable in as many environments as possible, with the concepts of persistence, machine communication, and interaction with hardware as fundamental and modular concepts.

To treat discoverability and comprehensibility as first class design considerations, projects should focus running code and tests against that code as demonstrators of project capabilities. Tests are means of learning what a software system does and how it works. Test results should be easy to replicate and reproduce.
